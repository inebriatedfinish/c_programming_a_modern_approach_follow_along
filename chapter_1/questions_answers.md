# C Programming - A Modern Approach (Second Edition)

### Chapter 1

Q: What does lint do?

A: lint is a tool that is used to check for errors in a program. This can be useful for finding errors before compiling and running said program. Helps find errors that the compiler would miss.

Q: Where did lint get its name?

A: It gets its name from the definition of "lint" which is "tiny bits of fabric that clothing sheds." The tool, lint, acts like a lint trap in a dryer would.
